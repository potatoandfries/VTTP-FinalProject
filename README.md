# 🛍️ StripeCart

> A fully functional e-commerce website with **Stripe** payment integration.  
> Built for developers looking to launch a modern, production-ready online store.

<img width="800" height="380" alt="image" src="https://github.com/user-attachments/assets/c3f6b4cd-91c6-4ab9-9f06-f5d83d9d5f15" />



## ✨ Features

- 🔐 **OAuth Authentication** – Sign in with Google, GitHub, or other providers
- 💳 **Stripe Integration** – Secure payment processing with test mode support
- 🛍️ **Product Catalog** – Browse, filter, and view products
- 🛒 **Shopping Cart** – Add/remove items, update quantities
- 📦 **Order Management** – View order history (authenticated users)
- 🎯 **Reactive Forms** – Type-safe form validation in Angular
- 🧠 **State Management** – NgRx for predictable state
- ☕ **Java Backend** – Spring Boot with Maven
- 🐳 **Docker Support** – Run with Docker Compose
- 📱 **Fully Responsive** – Works on all devices

## 🧰 Tech Stack

| Layer        | Technology |
|--------------|------------|
| Frontend     | Angular 15+ (TypeScript) |
| State Mgmt   | NgRx (Store, Actions, Reducers, Effects) |
| Styling      | Custom CSS |
| Backend      | Java / Spring Boot / Maven |
| Payments     | Stripe Java SDK |
| Auth         | OAuth 2.0 + Spring Security + JWT |
| Database     | PostgreSQL / MySQL / H2 (dev) |
| Container    | Docker + Docker Compose |
| Build Tool   | Maven |
